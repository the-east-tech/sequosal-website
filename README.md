# Sequosal website

Static websites served by Cloudflare Pages:

- `/` — Sequosal homepage
- `/flow/privacy` — Flow privacy policy
- `/stitch-gadget/` — Stitch Gadget website

## Cloudflare Pages

- Production branch: `main`
- Build command: none
- Build output directory: `.`

The repository root is the deployable output. Do not move these files back into
the Flow backend; the backend is deployed separately on Railway.
